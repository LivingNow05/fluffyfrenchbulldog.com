# /taste — High-End Frontend Taste Skill (Leonxlnx)

El usuario ha ejecutado el comando `/taste`. Esto activa el motor de diseño de alta gama de la suite `Leonxlnx/taste-skill`:

1. **Anti-Generico & Anti-Slop:** Prohibidos colores por defecto (rojo plano, azul puro) o diseños con aspecto de plantilla genérica.
2. **Estándares Visuales:**

   - Paletas tailoreadas HSL / Dark Mode luxury con dorados, ámbar y neón sutil.
   - Esquinas redondeadas suaves (16px a 20px), backdrop-filter glassmorphic y resplandores hover.
   - Layouts Bento Grid y micro-animaciones fluidas.
